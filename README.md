# Language Ranker — AAAI 2025 project page

Static project page for *Language Ranker: A Metric for Quantifying LLM Performance Across High and Low-Resource Languages*.

The page follows the restrained visual structure of [DynamicD](https://genforce.github.io/dynamicd/): centered title, author and institution lines, bracketed links, a large paper figure, and separate white sections for Overview, Results, and BibTeX. It uses independently written HTML and CSS.

## Sources

- [AAAI publication](https://ojs.aaai.org/index.php/AAAI/article/view/35038) supplies the published author affiliations, volume, issue, page range, and DOI.
- [arXiv version](https://arxiv.org/abs/2404.11553) supplies the method and results; Figures 1 and 2 in `assets/` are from its openly licensed HTML edition.
- [Research code](https://github.com/lizh9885/Language-Ranker/) is linked from the page.

Open `index.html` to preview locally. No build process is required.
